# 员工福利与体检制度

## 年度体检

公司为在职满一定期限的员工提供年度健康体检，体检机构从公司签约名单中选择。体检费用由公司承担，超出基础套餐的加项由员工自理。体检报告由机构直接提供给本人，公司不留存报告内容，只收取参检确认信息。

## 节日与生日福利

法定节日按公司统一安排发放节日福利；员工生日当月发放生日礼券。福利形式与额度每年由行政部核定并公示。

## 团建与活动经费

每个部门有年度团建经费额度，按人数核定，由部门负责人统筹使用，不得挪作他用，也不得以现金形式发放。团建活动须遵守《业务招待费与礼品管理办法》中关于场所的规定。

## 通讯与交通补贴

按岗位需要申请通讯补贴与交通补贴，标准由人力资源部按职级核定并在薪酬中发放，不再另行报销。

## 其他

本制度未列明的福利项目，以劳动合同约定与公司当年公示为准。
