# 考勤与打卡管理办法

## 考勤周期与工时

公司实行标准工时制，考勤周期为自然月。因岗位性质需要实行综合计算工时或不定时工作制的，由人力资源部报当地劳动行政部门审批后执行，并在劳动合同中约定。

## 打卡方式

员工须通过公司统一的考勤系统打卡，支持办公区闸机、企业微信与网页三种方式。考勤系统只记录打卡时点，不采集人脸等生物特征信息。代打卡属于严重违纪行为，一经查实按《员工手册》违纪条款处理。

## 外勤与出差打卡

外勤、出差期间无须到办公区打卡，但须在考勤系统中提交外勤/出差单作为出勤凭证。出差单须与 OA 的出差申请对应，两者不一致的以 OA 申请为准。

## 考勤结果确认

每月最后一个工作日，考勤系统自动生成当月考勤汇总并推送至员工确认；员工须在 3 个工作日内完成确认或发起异议。未确认且无异议的视为认可。

## 异常处理入口

迟到、早退、缺卡等异常的处理规则与补办流程，统一按《员工手册》考勤章节执行；本制度只规定记录与确认环节。
