# 发票与税务合规指引

## 可受理的票据类型

公司可受理增值税专用发票、增值税普通发票与合规电子发票。定额发票、手写票据、非税务监制的收据一律不予受理。发票内容须与实际业务一致，不得开具"办公用品""耗材"等笼统品名。

## 开票信息

开票信息以财务部每季度公示的版本为准，含公司全称、纳税人识别号、地址电话与开户行账号。因开票信息填写错误导致发票作废的，重开费用由报销人承担。

## 时限

发票开具后须在 90 个自然日内提交报销，超过时限的原则上不予受理，确有特殊原因的须由财务负责人审批。跨年发票按《员工手册》报销条款执行。

## 查验与留档

所有提交的发票均通过税务平台查验真伪，查验不通过的退回。会计凭证按国家规定留存，员工个人不得留存发票原件复印件用于其他用途。
