# 产品数据导入导出 FAQ

## 批量导入

支持通过 CSV/Excel 模板批量导入主数据。模板可在系统的"数据管理"页面下载，导入前系统会做字段校验并生成错误清单，校验不通过的整批回滚，不会产生半批数据。

## 增量同步

开放接口支持按时间戳增量拉取业务数据，适合与客户自有系统做定时同步。增量同步需要客户侧记录上次成功拉取的位置，系统不保存客户侧的游标。

## 导出任务

大批量导出以后台任务方式执行，任务完成后通过站内信通知下载。单个导出任务有行数上限，超过上限的建议按时间范围分批导出，或改用增量接口。

## 导出格式

结构化数据默认导出 CSV（UTF-8 带 BOM，便于 Excel 直接打开）与 JSON 两种格式；报表类可导出 Excel。具体可导出范围与当前订阅版本有关。

## 数据归属

客户数据的归属权属于客户，服务期内可随时导出；服务终止后的导出窗口见《产品FAQ》中的数据保留条款。
