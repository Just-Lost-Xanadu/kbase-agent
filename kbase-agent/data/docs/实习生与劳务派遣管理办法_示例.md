# 实习生与劳务派遣管理办法

## 适用范围

本办法适用于在校实习生、劳务派遣人员与退休返聘人员（以下统称"非正式用工人员"）。此类人员与公司不构成劳动关系，签署实习协议或由派遣单位签署劳动合同。

## 工时与出勤

实习生每周到岗天数由学校安排与部门协商确定，须遵守办公区管理规定与打卡要求。实习生不参与综合计算工时。

## 加班与调休（与员工规则的关键差异）

**非正式用工人员不适用《员工手册》的加班调休池规则**：其加班时长按实习协议约定的标准折算为实习补贴，不累积调休、不设调休有效期，也不参与离职时的调休清算。这是本制度对通用员工规则的明确排除，适用时以本制度为准。

## 假期

实习生按学校安排享有寒暑假，不享有年假、婚育假等员工专属假期；劳务派遣人员的假期由派遣单位按其规章制度管理，公司仅配合提供出勤记录。

## 账号与权限

非正式用工人员的信息系统账号由用工部门申请、设定有效期，到期自动停用，如需延长须重新审批，具体见《账号权限与访问审批流程》。

## 转正衔接

实习生毕业后入职的，实习生阶段不计入试用期，试用期自入职之日起重新计算。
