# 采购与供应商管理办法

## 采购分级

采购按金额分级：小额零星采购由部门自行执行并事后备案；达到一定金额的须走询比价；重大采购须公开招标。分级金额标准由财务部每年核定。

## 供应商准入

新供应商须提交营业执照、开票资质与合规承诺，由采购与法务共同审核后进入合格供应商名录。与合作方存在利益关系的经办人须主动申报并回避。

## 比价与定标

询比价应至少取得三家报价，形成比价记录并留存。定标结论须说明选择理由，最低价不是唯一依据。

## 验收与付款

到货后由需求部门验收并出具验收单。付款须凭合同、验收单与合规发票三单一致办理；发票的合规要求见《发票与税务合规指引》，合同签署流程见《合同评审与用印管理办法》。

## 供应商评价

每年对主要供应商进行评价，评价结果决定续用与份额调整。
