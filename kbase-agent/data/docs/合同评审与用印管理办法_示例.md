# 合同评审与用印管理办法

## 合同分类

合同按风险等级分为标准合同与非标准合同。使用公司标准模板且未改动核心条款的为标准合同，走简化流程；改动核心条款、金额较大或涉及知识产权归属的为非标准合同，须法务逐条评审。

## 评审流程

经办人在 OA 发起合同评审，附对方主体资料与商务条款。评审由法务、财务与业务三方并行出具意见，任何一方提出否决意见的不得用印。

## 用印审批

用印须凭已完成的评审结论申请，印章由综合管理部集中保管，用印过程留痕并登记用印台账。禁止携带空白盖章文件外出。

## 电子签章

公司认可的电子签章平台与实体印章具有同等效力，使用前须确认对方接受电子签章形式。

## 归档

合同签署完成后由经办人移交原件归档，扫描件上传合同管理系统；付款条件与《采购与供应商管理办法》衔接。
