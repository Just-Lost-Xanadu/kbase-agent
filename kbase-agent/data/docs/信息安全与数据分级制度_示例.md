# 信息安全与数据分级制度

## 数据分级

公司数据按敏感程度分为公开、内部、秘密、绝密四级。客户名单、合同金额、个人身份信息属于秘密级及以上，任何情况下不得存储于个人设备或公共网盘。

## 外发审批

秘密级及以上数据对外提供须经数据Owner与法务双重审批，并留存审批记录。对外传输优先使用公司统一的数据交换平台，禁止使用个人邮箱、即时通讯工具传输。

## 终端与加密

公司配发的终端默认开启全盘加密与屏幕锁定；接入公司网络的个人终端须通过合规检查。移动存储介质须使用公司统一加密盘。

## 审计与追责

数据访问与导出行为全程留痕并定期审计。违反本制度造成数据泄露的，按情节给予处分直至解除劳动合同，涉嫌犯罪的移交司法机关。
