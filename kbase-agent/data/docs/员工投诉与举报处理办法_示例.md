# 员工投诉与举报处理办法

## 受理范围

本办法受理员工对违规违纪、利益冲突、职场不当行为与安全隐患的投诉举报。涉及薪酬争议、绩效结论等个人权利事项的，走《绩效改进与申诉办法》或劳动争议渠道。

## 举报渠道

公司设合规邮箱与举报电话两个渠道，均可匿名提交。受理部门为合规与人力资源部联合小组，与举报事项有直接利害关系的人员须回避。

## 处理流程

受理后 3 个工作日内完成初步核实并决定是否立案；立案后开展调查，调查过程保护举报人身份，材料按秘密级信息管理。调查结论与处理决定在规定时限内反馈举报人（匿名举报无法反馈的除外）。

## 反报复

任何形式的打击报复行为一经查实从重处理，直至解除劳动合同。

## 与《员工手册》的关系

违规行为的具体处理档位以《员工手册》的保密与廉洁条款为准；本办法规定举报与调查的程序。
