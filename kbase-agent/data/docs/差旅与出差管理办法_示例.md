# 差旅与出差管理办法

## 适用范围

本办法适用于境内出差、境外出差及本地用车三类公务出行。出差前须在 OA 发起出差申请，写明事由、行程、预算与随行人员，经直属主管审批。境外出差另需财务与法务会签，并提前 10 个工作日提交。

## 境外差旅

境外住宿按当地货币限额执行，由财务按下榻城市的商务酒店均价每半年核定一次，不适用境内一城一价的标准。境外餐补按实际出差天数发放，不以发票实报。境外差旅的保险由公司统一购买，个人不得自行加购后报销。

## 用车与市内交通

公务用车优先使用公司签约网约车账户，个人先行垫付的需在行程结束后 5 个工作日内提交电子行程单。市内交通仅限出发地与目的地之间的合理路线，绕行或私人行程不予报销。

## 变更与取消

行程变更须在 OA 提交变更单；因个人原因取消已预订的机票酒店的，退票费与违约金由个人承担；因公务原因取消的凭取消证明全额报销。
