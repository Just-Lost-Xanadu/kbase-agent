# 绩效改进与申诉办法

## 绩效改进计划

考核结果低于合格线或连续出现明显下滑的员工，由直属主管与其共同制定绩效改进计划，明确改进目标、辅导方式与观察周期，并报人力资源部备案。改进期内公司提供必要的培训与资源支持。

## 结果申诉

员工对考核结果有异议的，可在结果公示后 5 个工作日内向人力资源部提交书面申诉，说明理由并附佐证材料。人力资源部组织复核，必要时召集由业务负责人与HR组成的复核小组。

## 复核时限

复核应在收到申诉后 10 个工作日内完成并书面反馈。复核期间不影响当期薪酬发放。

## 结果的效力

绩效档位划分、结果应用等实体规则以《薪酬与绩效制度》为准；本办法只规定改进与申诉的程序。

## 记录与保密

申诉材料与复核记录按秘密级信息管理，仅限参与复核的人员知悉。
