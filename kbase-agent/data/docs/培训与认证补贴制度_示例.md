# 培训与认证补贴制度

## 培训类型

培训分为公司统一组织的内训、外部公开课与在线课程三类。内训由人力资源部按年度计划组织，全员或按岗位参加。

## 外部培训申请

参加外部培训须提前在 OA 提交申请，说明课程内容、费用预算与与岗位的相关性，由直属主管与人力资源部审批。同一课程原则上不重复外派。

## 认证考试补贴

与岗位直接相关的职业资格认证，考试通过后公司可报销考试费与教材费，具体上限按认证级别分档。报销凭据的合规要求见《发票与税务合规指引》，补贴的发放时点与薪酬无关，不纳入绩效工资基数。

## 服务期约定

单次补贴金额达到一定标准的，公司与员工签署培训服务期协议；服务期内主动离职的，按未履行期限比例返还。

## 知识回馈

参加外部培训的员工须在返岗后一定期限内组织一次内部分享，分享材料纳入公司知识库。
