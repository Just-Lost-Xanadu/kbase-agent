把你要喂给 Agent 的业务文档放进本目录，`app/retrieval/loader.py` 负责解析。支持 `.md` / `.txt`（UTF-8 直读）、`.docx`（段落+表格）、`.xlsx`（各工作表转文本行）、`.pdf`（文本层抽取；扫描件/图片 PDF 需 OCR，列为扩展）。文件名以 `_` 开头的文件会被 loader 忽略（如本文件），只用于写说明、不参与建索引。

当前语料共 6 篇（均 .md），评测集 `eval/questions.jsonl` 的 40 条问题就基于它们编写：

| 文件名 | 内容 | 覆盖问题数 |
|---|---|---|
| `员工手册_示例.md` | 年假/加班/考勤/差旅/发票/请假/保密 | 14 |
| `产品FAQ_示例.md` | 部署/限流/加密/数据保留/权限 | 9 |
| `产品交付与售后FAQ_示例.md` | 交付/响应/升级/POC | 4 |
| `IT与账号管理制度_示例.md` | 账号/密码/数据外发/设备/软件 | 4 |
| `入职转正与离职制度_示例.md` | 入职/转正/离职/晋升 | 4 |
| `薪酬与绩效制度_示例.md` | 发薪/绩效/年终奖/调薪 | 5 |

使用注意：
- **新增** `.md/.txt/.docx/.xlsx/.pdf` 文件后跑 `python scripts/index_docs.py` 增量入库；
- **替换同名文件 / 大改语料**：删 `data/chroma/` 后重建，避免旧分块残留；评测集若换领域要一起重写。
