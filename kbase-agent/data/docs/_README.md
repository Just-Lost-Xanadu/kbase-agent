把你要喂给 Agent 的业务文档放进本目录（`.md` / `.txt` 均可，`app/retrieval/loader.py` 负责解析；`.pdf` 需要额外解析库，列为后续扩展）。文件名以 `_` 开头的文件会被 loader 忽略（如本文件），只用于写说明、不参与建索引。

当前语料共 5 篇（知识库 + 制度 + 产品），评测集 `eval/questions.jsonl` 的 35 条问题就基于它们编写：

| 文件名 | 内容 | 覆盖问题数 |
|---|---|---|
| `员工手册_示例.md` | 年假/加班/考勤/差旅/发票/请假/保密 | 14 |
| `产品FAQ_示例.md` | 部署/限流/加密/数据保留/权限 | 9 |
| `产品交付与售后FAQ_示例.md` | 交付/响应/升级/POC | 4 |
| `IT与账号管理制度_示例.md` | 账号/密码/数据外发/设备/软件 | 4 |
| `入职转正与离职制度_示例.md` | 入职/转正/离职/晋升 | 4 |

想换成你自己的领域时，把语料换掉、同步把 `eval/questions.jsonl` 重写即可。
