# 竞业限制与保密协议实施办法

## 保密义务

全体在职员工均负有保密义务，保密范围包括技术资料、客户信息、报价与成本数据、未公开的经营计划。保密义务不因离职而终止，具体期限按协议约定。

## 竞业限制的适用对象

竞业限制只对**签署了专项竞业限制协议**的人员生效，通常覆盖高级管理人员、高级技术人员与其他负有保密义务的人员。未签署专项协议的人员不承担竞业限制义务。签署人员名单由人力资源部确定并在协议中列明。

## 补偿与违约金

竞业限制期内公司按月支付经济补偿，逾期未支付达到约定期限的，员工可主张解除竞业限制。违反竞业限制约定的，按协议承担违约责任。

## 与保密义务的区别

保密义务无需支付补偿且不设期限上限（以信息仍属秘密为前提）；竞业限制必须支付补偿且有明确期限。两者是不同义务，不可互相替代。

## 解除

公司可在员工离职时或竞业限制期内书面通知放弃竞业限制要求，自通知送达之日起停止支付补偿。
