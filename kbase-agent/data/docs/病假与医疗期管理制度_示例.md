# 病假与医疗期管理制度

## 病假申请

病假须在 OA 提交申请并上传医院出具的病假证明。突发疾病可先电话或 IM 报备直属主管，返岗后 2 个工作日内补齐流程与材料。连续病假超过 3 天的，须提供二级及以上医院的诊断证明。

## 医疗期

医疗期按员工实际工作年限与本企业工作年限分段确定，最短 3 个月、最长 24 个月。医疗期内公司不得依据劳动合同法第四十条解除劳动合同。

## 病假工资

病假工资按当地最低工资标准的一定比例计发，具体比例按工龄分档，由薪酬组在算薪时执行。医疗期满仍需治疗的，按国家规定办理。

## 复岗

长期病假返岗前须提交复工证明；岗位已调整的由部门与人力资源部共同安排过渡期。
