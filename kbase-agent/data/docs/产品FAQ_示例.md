# 产品 FAQ

## 私有化部署要求

单机试用版：4 核 8G 一台即可，适合功能验证与小型场景。生产高可用版：至少 3 台节点（2 应用 + 1 数据库），应用节点 8 核 16G，数据库节点建议 16G 以上并配置主从。支持主流云厂商 ECS 与本地 IDC，运行环境要求 Linux（CentOS 7+ / Ubuntu 20.04+）与 Docker 20.10+。

## API 限流

API 默认 QPS 为 50，突发可到 100。超过限额返回 HTTP 429，请在收到 429 后指数退避重试（建议从 1s 起、最多 5 次，间隔按 1s/2s/4s/8s/16s 递增）。需要更高 QPS 请联系商务升级套餐；限流阈值按租户维度隔离，单个租户超限不影响其他租户。

## 数据加密

传输层全部走 TLS 1.2+；存储层使用 AES-256 加密落盘，密钥由客户托管或平台 KMS 托管，客户可选。日志不记录明文请求体，脱敏后的审计日志仅保留 180 天。支持客户自带证书（BYOC）与国密 SM4 存储加密选项。

## 数据保留

试用版到期后，数据保留 30 天，期间可随时导出为 JSON/CSV。正式版到期未续费，保留 60 天后清空，导出窗口同前。账号删除后，关联的检索索引与缓存数据在 24 小时内同步清理。

## 账号与权限

支持 RBAC 角色权限，最小粒度为单应用内功能权限。管理员可设置 IP 白名单与登录二次验证，支持对接企业微信、钉钉、LDAP 单点登录。所有敏感操作（导数据、删库、改权限）均记录审计日志并支持导出。

## 浏览器与兼容性

Web 端支持 Chrome、Edge 最新两个大版本，移动端支持企业微信内置浏览器。产品以 Restful API 对外提供服务，SDK 覆盖 Java、Python、Go。
