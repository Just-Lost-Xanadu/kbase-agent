# 产品 FAQ（示例知识库内容）

## 私有化部署要求

单机试用版：4 核 8G 一台即可。生产高可用版：至少 3 台节点（2 应用 + 1 数据库），应用节点 8 核 16G。支持主流云厂商 ECS 与本地 IDC。

## API 限流

API 默认 QPS 为 50，突发可到 100。超过限额返回 HTTP 429，请在收到 429 后指数退避重试（建议从 1s 起、最多 5 次）。需要更高 QPS 请联系商务升级套餐。

## 数据加密

传输层全部走 TLS 1.2+；存储层使用 AES-256 加密落盘，密钥由客户托管或平台 KMS 托管，客户可选。日志不记录明文请求体。

## 数据保留

试用版到期后，数据保留 30 天，期间可随时导出为 JSON/CSV。正式版到期未续费，保留 60 天后清空，导出窗口同前。

## 账号与权限

支持 RBAC 角色权限，最小粒度为单应用内功能权限。管理员可设置 IP 白名单与登录二次验证。
