# 晋升与内部转岗制度

## 晋升通道

公司设置管理与专业双通道。专业通道按能力等级逐级晋升，管理通道需具备团队管理经历。通道之间可以转换，转换当年需重新评定等级。

## 晋升评审周期

晋升评审原则上每年组织，由部门提名与个人自荐两种方式产生候选人。评审材料包括业绩记录、能力评价与述职材料。

## 内部转岗

在职满一定期限的员工可申请内部转岗。转岗须经原部门、接收部门与人力资源部三方确认；转岗后设置适应期，适应期内不通过的回到原岗位或另行安排。

## 试用期的关系

新员工试用期考核与转正流程按《入职转正与离职制度》执行，与本制度规定的晋升评审不是同一套流程，不得相互替代。

## 生效与公示

晋升结果公示后生效，薪酬调整按《薪酬与绩效制度》中调薪条款执行。
