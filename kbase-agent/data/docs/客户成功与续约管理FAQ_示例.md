# 客户成功与续约管理 FAQ

## 健康度评估

客户成功团队按使用活跃度、工单情况与关键功能采纳度综合评估客户健康度，分为健康、观察、风险三档。评估结果用于决定服务投入的优先级。

## 季度业务回顾

企业客户每季度可安排一次业务回顾，内容包括使用数据、达成情况与下一阶段目标。回顾材料由客户成功经理提前准备。

## 续约流程

订阅到期前一段时间，客户成功经理会主动联系确认续约意向并出具续约方案。续约价格与折扣政策按当期商务政策执行。

## 增购与扩容

使用量接近配额时系统会提前预警，客户可随时增购席位或调用量，增购部分按剩余周期折算。

## 流失预警与挽留

进入风险档且长期无活跃的客户，由客户成功经理发起挽留方案。已决定不再续约的客户，按《产品数据导入导出FAQ》协助完成数据导出。
