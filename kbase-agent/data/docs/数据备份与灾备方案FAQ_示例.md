# 数据备份与灾备方案 FAQ

## 备份策略

生产数据每日做一次全量备份，并在日内按周期做增量备份。备份文件加密存储，与生产环境使用不同的访问凭据。

## RPO 与 RTO

不同版本的恢复目标不同：标准版提供按天的恢复点目标，企业版可做到更短的恢复点与恢复时间目标，具体指标在服务协议中约定。

## 异地灾备

企业版支持跨可用区部署；对灾备要求更高的客户可选择异地灾备方案，异地副本的同步方式与延迟在方案书中列明。

## 恢复演练

每半年组织一次恢复演练，演练记录与实测恢复时长向企业客户提供。演练在独立的恢复环境进行，不影响生产。

## 客户自助备份

客户可通过导出功能自行留存一份数据副本，导出方式见《产品数据导入导出FAQ》。

## 与高可用的关系

高可用解决的是单点故障导致的短时不可用，数据备份解决的是数据损坏与误删除，两者不能互相替代。部署台数见《产品FAQ》。
