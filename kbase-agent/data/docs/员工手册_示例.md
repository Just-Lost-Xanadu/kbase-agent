# 员工手册（示例知识库内容）
> 说明：这是第 1 周拿来练手的示例文档。后续可以把这里替换成你想投的公司公开资料、自己的笔记等，让项目"有真实感"。

## 年假

正式员工入职满一年后，每年享有带薪年假 10 天。按自然年计算，当年未休完的年假最多结转 3 天至次年一季度末，其余作废。离职时未休年假按日工资折算补偿。

## 加班

加班需提前在 OA 提交申请，写明原因与预估时长，由直属主管审批。工作日加班按 1.5 倍调休、节假日加班按 2 倍调休计入调休池，调休需在 3 个月内用完，逾期清零。

## 考勤与补卡

上下班需打卡。忘记打卡的，须在 3 个工作日内通过 OA 提交补卡申请，每月补卡不得超过 3 次，超出的按迟到处理。

## 差旅报销

出差住宿：一线城市（北上广深杭）每晚不超过 500 元，其他城市不超过 350 元，超限部分自理。交通与餐补按公司标准凭票实报，发票抬头须为公司全称。

## 发票与报销

报销须提供合规增值税发票。发票丢失的，可提供商户开具的发票复印件加盖章，或银行流水加说明，由财务审批后按 80% 报销。

## 保密与廉洁

员工在客户现场或对外合作中，不得私自拍照、录音、拷贝客户资料；严禁收受合作方礼品礼金。违反者视情节给予警告直至解除劳动合同，涉嫌违法的移交司法机关。
