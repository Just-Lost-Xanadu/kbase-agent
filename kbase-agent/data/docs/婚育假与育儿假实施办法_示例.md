# 婚育假与育儿假实施办法

## 婚假

员工依法办理结婚登记可享受婚假，须在登记之日起一年内使用，逾期不补。申请时提交结婚证复印件。

## 产假与陪产假

女员工产假按当地人口与计划生育条例执行，难产、多胞胎的按规定顺延。男员工陪产假在配偶分娩后连续使用，不得拆分。

## 育儿假

子女满三周岁前，符合条件的员工每年可享受育儿假，按子女数量分别计算。育儿假当年有效，不结转、不折现。

## 哺乳时间

哺乳期女员工每天享有哺乳时间，可合并使用也可折算为延迟到岗或提前离岗，具体与直属主管协商。

## 与年假的关系

婚育假与年假的申请入口、审批人相同，但额度互不占用；年假结转规则仍按《员工手册》执行。
