# 弹性工作与远程办公管理办法

## 弹性上下班

在保证每日工时与协作时段的前提下，员工可在规定区间内自行选择上下班时间，弹性时段由各部门根据业务节奏确定并公示。弹性上下班不改变考勤要求，仍须按规定打卡。

## 远程办公

远程办公须提前一天在 OA 提交申请，写明远程地点与当日工作计划，由直属主管审批。每周远程天数上限由部门设定。远程期间须保持在线并参加既定会议。

## 考勤与异常

远程办公当天仍按正常考勤时段打卡；因网络故障无法打卡的，按《员工手册》补卡条款提交材料，但每月补卡次数与现场办公合并计算。

## 居家设备

公司不额外配发居家办公设备；使用个人设备接入公司系统的，须遵守《信息安全与数据分级制度》。
