# 薪酬结构与个税申报说明

## 薪酬构成

薪酬由基本工资、岗位工资、绩效工资与补贴四部分构成。绩效工资按考核结果浮动发放，具体评定规则见《薪酬与绩效制度》。补贴包含通讯、交通等固定项，按《员工福利与体检制度》核定。

## 发放与代扣

工资通过银行代发，公司依法代扣代缴个人所得税与社保公积金个人部分。薪资明细通过薪酬系统推送，员工对明细有疑问的应在收到后 5 个工作日内提出。

## 个税专项附加扣除

员工须在个人所得税 App 中自行填报专项附加扣除信息，并在信息变化时及时更新。公司仅按员工填报结果申报，不代为判断扣除资格。

## 薪资保密

薪酬信息属于秘密级信息，员工不得相互打听或传播。泄露薪酬信息按《员工手册》纪律条款处理，涉及数据的按《信息安全与数据分级制度》执行。

## 年度汇算

个税年度汇算清缴由员工个人通过税务渠道办理；需要公司提供收入纳税明细的，向薪酬组提出申请。
