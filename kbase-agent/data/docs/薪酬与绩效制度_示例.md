# 薪酬与绩效制度（示例知识库内容）

## 薪酬构成与发薪

月薪由基本工资、岗位绩效与各类补贴构成。每月 10 日发放上月工资，遇法定节假日提前至最近工作日发放，不推迟。新员工入职当月按实际出勤天数折算发放。每月工资条可在 OA 自助查询，含各项构成与个税代扣明细。

## 绩效评定

绩效考核每季度一次，分为 S、A、B、C、D 五档。评定由直属主管初评，经部门校准会统一拉齐后生效。连续两季度评为 C 或任一季度评为 D，触发绩效改进计划（PIP），周期 2 个月，期满由主管与人力复评决定去留。

## 年终奖

年终奖与年度绩效等级和当年在职月数挂钩：年终奖 = 基数 × 绩效系数 ×（当年在职月数 ÷ 12）。绩效系数按年度绩效等级确定，S 档 1.5、A 档 1.2、B 档 1.0、C 档 0.6、D 档为 0。年终奖随次年 1 月工资一并发放，发放日前离职的不享受当年年终奖。

## 调薪

年度调薪窗口为每年 3 月，依据上一自然年度绩效等级确定调薪幅度；绩效为 C 及以下原则上不调薪。晋升带来的调薪随晋升评审即时生效，具体见《入职转正与离职制度》晋升条款。年度调薪幅度仅本人与人力知悉，不得相互打听。
