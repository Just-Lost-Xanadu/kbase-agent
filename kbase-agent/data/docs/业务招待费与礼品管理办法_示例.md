# 业务招待费与礼品管理办法

## 招待费标准

业务招待须事前在 OA 提交招待申请，写明客户单位、人数、事由与预估金额。人均标准按客户级别分档，超标部分需由事业部负责人书面说明。招待一律使用公司签约餐厅或协议酒店，禁止在娱乐场所列支。

## 礼品与纪念品

对外赠送纪念品须走统一采购渠道，单件价值与年度累计额度由市场部核定。赠送与收受均须在 OA 登记备查，登记信息包括对象单位、事由、物品名称与价值。

## 收受礼品

员工不得收受合作方的现金、有价证券与贵重物品。收到无法当场拒绝的礼品，须在 24 小时内在 OA 登记并交综合管理部统一处置；价值较低且易腐坏的食品类礼品，可登记后由团队内部消化，但不得由个人带离公司。

## 违规处理

未登记、瞒报或私下留用礼品礼金的，按违纪处理；金额较大或多次发生的，解除劳动合同并追偿。
