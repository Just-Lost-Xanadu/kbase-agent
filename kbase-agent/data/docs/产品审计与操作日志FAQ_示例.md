# 产品审计与操作日志 FAQ

## 操作审计

系统记录管理类操作（账号创建、权限变更、配置修改、数据导出）的操作人、时间、来源 IP 与操作对象，形成审计日志。审计日志本身不可修改、不可删除。

## 留存期限

审计日志默认留存期限与客户订阅版本有关，企业版可按合规要求申请延长。留存期满后按《产品FAQ》中的数据保留规则处理。

## 查询与导出

管理员可在控制台按时间范围、操作人与操作类型检索审计日志，并导出为文件用于内外部审计。导出行为本身也会被记入审计日志。

## 与业务日志的区别

审计日志回答"谁做了什么操作"，业务日志用于排障与性能分析，两者存储分离、留存策略不同。业务日志中记录的字段范围见《产品FAQ》。

## 合规配合

客户接受监管检查需要服务方出具说明的，可通过工单提出，由合规团队配合。
