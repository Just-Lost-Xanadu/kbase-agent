# 等保与合规认证 FAQ

## 等保备案

产品在客户侧部署时，等保备案主体为使用方。服务方提供系统定级建议、安全建设整改说明与测评配合材料，协助客户完成测评。

## 已有认证

公司定期开展信息安全与隐私保护相关的外部审计，认证证书与审计报告可在签约前的尽调环节提供给客户。认证范围与有效期以证书原件为准。

## 渗透测试

产品每年至少委托第三方开展一次渗透测试，高危问题在约定时限内修复并出具复测报告。客户如需自行委托渗透测试，须提前报备时间窗与测试范围，避免影响生产。

## 安全事件响应

发生安全事件时，服务方按约定的时限通知受影响客户，提供事件说明与整改措施，并配合监管报送。

## 数据传输与存储

加密相关的具体实现见《产品FAQ》；内部数据的分级与外发审批见《信息安全与数据分级制度》。
